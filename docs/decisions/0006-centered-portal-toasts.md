# Centered portal toast notifications

- Rule: Frontend design system section 14 specifies bottom-right toast placement.
- Decision: Portal toasts appear centered in the viewport, with the icon above the message and automatic dismissal after 4 seconds.
- Reason: The product owner requested prominent, quickly noticed feedback for the school portal workflow.
- Scope: `apps/web/components/ui/sonner.tsx` and the global portal toast styles.
- Date: 2026-10-01
